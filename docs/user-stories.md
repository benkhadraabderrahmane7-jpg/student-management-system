# User stories
- As a user, I want to add a student with ID, name, age, and type so I can manage student records.
- As a user, I want to view all students sorted by ID so I can find records easily.
- As a user, I want to search by ID so I can see a student's information.
- As a user, I want to delete a student by ID so I can remove old records.
- As a user, I want my students to remain after restarting the program.
- As a user, I want clear messages for invalid input and duplicate IDs.
